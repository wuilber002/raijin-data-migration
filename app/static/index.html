Plataforma de migração de dados

RAIJIN

Versão {{RAIJIN_VERSION}} · build {{RAIJIN_BUILD_REVISION}}

RAIJIN conduz migrações controladas de AWS S3 para OCI Object Storage, com inventário persistente, ondas operacionais, retomada segura, rastreabilidade e verificação criptográfica de integridade.

Inspirado em Raijin, a divindade japonesa do trovão, o emblema representa força, movimento e condução precisa: cada objeto sai da origem com evidências de transferência e chega ao destino preservando sua integridade operacional.

Backend cloud simulator

FUJIN

Versão {{FUJIN_VERSION}}

FUJIN simula AWS S3, OCI Object Storage, rede e tempo por contrato versionado, permitindo que os workers reais do RAIJIN sejam validados sem chamadas aos provedores.

Inspirado em Fūjin, a divindade japonesa do vento, ele cria cenários determinísticos, preserva evidências operacionais e reproduz falhas para validar o comportamento da migração com segurança.
